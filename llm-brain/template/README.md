# {{OWNER}}'s brain 🧠

Ideas, projects, thoughts, tools and notes, captured from anywhere (phone, chat, terminal) and picked up later from anywhere. Kept in Markdown and co-written with Claude through the [llm-brain skill](https://github.com/LuisLombaMartinez/llm-brain-skill).

| Folder | Type |
|---|---|
| `ideas/` | Something to come back to, not yet a project |
| `projects/<slug>/` | Something I've decided to build or do (`README.md` + extra files) |
| `thoughts/` | Personal reflections |
| `tools/` | Claude skills, MCPs, plugins, apps and libraries to try or in use |
| `notes/` | Reference knowledge and how-tos |

- [`GLOSSARY.md`](GLOSSARY.md): exact definitions and which words to use or avoid. Change it to fit how you think.
- [`CLAUDE.md`](CLAUDE.md): conventions every Claude session follows.

**Usage:** tell Claude "save to my brain: …", "add this to my brain as a thought", "what's in my brain about X?", "review the ideas in my brain" or "which tools in my brain haven't I tried?".
